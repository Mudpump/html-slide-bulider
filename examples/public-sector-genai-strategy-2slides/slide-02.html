공공부문 생성형 AI 도입 전략

생성형 AI는 안전한 기준 → 공통 기반 → 우선 적용 업무
→ 확산 역량의 순서로 추진해야 합니다.

안전한 기준 수립
01

개인정보, 보안, 저작권, 환각 대응, 책임 소재를 포함한 공공 활용 가이드라인을 마련합니다.

공통 기반 구축
02

공공 데이터 품질, API 연계, 내부 지식 검색, 로그·감사 체계, 보안형 AI 활용 환경을 정비합니다.

우선 적용 업무 선정
03

민원 응대, 문서 요약, 정책 자료 조사, 내부 지식 검색처럼 효과와 위험이 명확한 업무부터 실증합니다.

확산 역량 강화
04

담당자의 프롬프트, 검증, 업무 재설계 역량을 높이고 재사용 가능한 적용 모델을 축적합니다.

Phase 1
위험 기준과 승인 절차 정의
Phase 2
데이터·도구 연계 기반 마련
Phase 3
고효과 업무 중심 파일럿
Phase 4
성과 지표와 운영 모델 확산
핵심 전환
AI를 도입하는 사업에서
AI와 함께 일하는 공공 업무 체계를 운영하는 단계로
