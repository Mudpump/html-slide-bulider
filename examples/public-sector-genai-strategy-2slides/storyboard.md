## Slide 02

- Role: Strategy brief
- Main message: 공공부문 생성형 AI는 "안전한 기준 → 공통 기반 → 우선 적용 업무 → 확산 역량"의 순서로 추진해야 한다.
- Visual layout: 4개 전략 축 매트릭스와 하단 실행 로드맵, 우측 결론 콜아웃
- Content:
  - 1. 안전한 기준 수립: 개인정보, 보안, 저작권, 환각 대응, 책임 소재를 포함한 공공 활용 가이드라인 마련
  - 2. 공통 기반 구축: 공공 데이터 품질 관리, API 연계, 내부 지식 검색, 로그·감사 체계, 보안형 AI 활용 환경 정비
  - 3. 우선 적용 업무 선정: 민원 응대, 문서 요약, 정책 자료 조사, 내부 지식 검색 등 효과와 위험이 명확한 업무부터 실증
  - 4. 확산 역량 강화: 담당자의 프롬프트·검증·업무 재설계 역량을 높이고, 성과 지표와 재사용 가능한 적용 모델을 축적
  - Closing callout: AI를 "도입"하는 사업에서 AI와 함께 일하는 공공 업무 체계를 "운영"하는 단계로 전환
- Speaker note:
  - 두 번째 장은 바로 실행 논의로 이어질 수 있도록 기준, 기반, 업무, 역량의 4축으로 정리한다.
