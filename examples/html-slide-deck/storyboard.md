## Slide 01

- Role: Context and problem framing
- Main message: 에이전틱 AI는 단순 생성형 AI 활용을 넘어, 공공 디지털 전환의 운영 방식과 정책 지원 체계를 다시 설계하게 만든다.
- Visual layout: Executive Brief 스타일의 상단 핵심 문장 + 하단 3개 변화 신호 카드
- Content:
  - 에이전틱 AI는 사용자의 단발성 요청에 답하는 수준을 넘어 목표 설정, 작업 분해, 도구 사용, 결과 검토를 반복하는 방향으로 진화
  - 공공 영역에서는 행정 서비스, 데이터 기반 정책, 업무 자동화, 국민 접점 서비스에 구조적 변화 가능성 확대
  - 정책 지원은 기술 도입 지원을 넘어 신뢰성, 책임성, 데이터 거버넌스, 현장 적용 역량까지 포함해야 함
- Speaker note:
  - 첫 장은 기술 설명보다 “왜 NIA의 정책 지원 방향이 달라져야 하는가”를 여는 장으로 사용
  - TBD: NIA의 기존 역할이나 현재 정책 사업명을 넣으면 설득력이 높아짐

## Slide 02

- Role: Policy support direction
- Main message: NIA는 에이전틱 AI 확산을 위해 공공 적용 기준, 데이터/인프라 기반, 실증 생태계, 역량 전환을 함께 지원해야 한다.
- Visual layout: 4개 정책 축 매트릭스 + 우측 결론 콜아웃
- Content:
  - 적용 기준: 에이전트의 자율성 수준, 책임 소재, 검증 절차, 위험 등급에 대한 공공 가이드라인 마련
  - 데이터/인프라: 공공 데이터 품질, API 연계, 보안 환경, 모델/도구 접근 기반 정비
  - 실증 생태계: 부처·지자체·민간이 함께 검증할 수 있는 과제 발굴과 샌드박스 운영
  - 역량 전환: 공무원과 공공기관 실무자가 에이전틱 워크플로우를 설계·감독할 수 있도록 교육과 방법론 제공
