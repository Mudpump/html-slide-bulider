## Slide 02

- Role: Expansion strategy
- Main message: 공공부문 에이전틱 AI는 "기준 정립 -> 공통 기반 -> 우선 과제 실증 -> 역량 확산"의 순서로 단계화해야 한다.
- Visual layout: 4개 전략 축 매트릭스 + 하단 단계형 로드맵 + 우측 결론 콜아웃
- Content:
  - 기준 정립: 자율성 수준, 위험 등급, 책임 소재, 승인 절차, 로그·감사 기준을 포함한 공공 가이드라인 마련
  - 공통 기반: 공공 데이터 품질, API 연계, 보안 실행환경, 도구 호출 체계, 내부 지식 검색 기반 정비
  - 우선 과제 실증: 민원·상담 보조, 정책 자료 조사, 문서 작성·검토, 현장 점검 지원 등 효과와 위험이 명확한 업무부터 검증
  - 역량 확산: 공공기관 실무자가 에이전틱 워크플로우를 설계·감독·평가할 수 있도록 교육, 방법론, 성과 지표 제공
  - Closing callout: AI를 "도입"하는 사업에서 AI와 함께 일하는 공공 운영 체계를 "운영"하는 단계로 전환
- Speaker note:
  - 마지막 장은 바로 실행 논의로 넘어갈 수 있도록 4축 전략과 단계적 확산 흐름을 함께 제시
  - 필요하면 NIA 내부 사업명, 현재 추진 과제, 부처 협업 구조를 각 축 아래에 추가 가능
